# 📚 BiblioFácil - Sistema de Gestão de Biblioteca Escolar

Aplicação web desenvolvida em Python com o framework Django (arquitetura MTV) para controle de acervo bibliográfico, autores e empréstimos escolares.

## 🚀 Tecnologias Utilizadas
* Python 3 & Django
* SQLite3 & ORM Django
* HTML5, CSS3 & Bootstrap 5
* Gunicorn & WhiteNoise (Deploy no Render)
